# Belajar JavaScript Dasar

Repositori catatan belajar JavaScript dasar dari Teching Academy. Saat ini mencakup **Pertemuan 1 sampai 3**.

## Struktur Folder

```
javascript-basic/
├── pertemuan-1/
├── pertemuan-2/
└── pertemuan-3/
```

Setiap folder berisi file HTML dan folder `scripts` untuk kode JavaScript-nya.

## Cara Menjalankan

Buka file HTML pertemuan di browser, lalu tekan `F12` untuk melihat hasilnya di Console.

## Ringkasan Materi

| Pertemuan | Deskripsi |
|---|---|
| 1 | Pengenalan dasar JavaScript: variabel (`const` dan `let`), tipe data, operator, kondisi `if / else`, dan pengenalan DOM. |
| 2 | Alur program (*control flow*): ternary, `switch case`, dan perulangan (`for`, `while`, `do...while`, `for...of`, `for...in`), serta menampilkan data ke halaman HTML. |
| 3 | Function dan scope: function biasa, arrow function, parameter default, dan `export` untuk memakai function di file lain. |
